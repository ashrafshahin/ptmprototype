# Path To Marriage (PTM) Asset Directory

This directory is prepared to store original assets exported from Figma or client media:

- `/public/assets/ptm/logos/`: Brand logos, marks, and wordmarks (SVG / PNG)
- `/public/assets/ptm/icons/`: Matrimonial-specific custom iconography
- `/public/assets/ptm/illustrations/`: Hero and empty-state illustrations
- `/public/assets/ptm/avatars/`: Sample matrimonial candidate photo assets

When Figma design attachments or assets are provided, place them here and reference them via `/assets/ptm/...`.
